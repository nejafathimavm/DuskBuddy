# DuskBuddy

DuskBuddy is an AI-powered smart desk companion robot built using ESP32, computer vision, voice interaction, and robotics concepts.

## Features
- Voice interaction
- Gesture control
- ESP32-based hardware
- AI assistant functionality
- Computer vision integration
- Smart desk companion robot

## Technologies Used
- Python
- ESP32
- OpenCV
- ROS2
- WebSockets

## Project Goal
To create an interactive smart robotic companion that can assist users through voice, gestures, and intelligent responses.
